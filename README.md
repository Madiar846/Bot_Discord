# Discord AI Analyzer Bot

Discord-бот на Python, интегрированный с OpenAI API (модель `gpt-4o-mini`). Бот предназначен для экспресс-анализа пользовательских запросов и формирования структурированных ответов.

# Функционал
* Обработка команд:** Команда `!analyze <запрос>` для отправки задачи боту.
* Структурированный вывод:** Системный промпт задаёт чёткую структуру ответа (1. Причины, 2. Контекст, 3. Вывод) с автоматическим дисклеймером.
* Обработка ошибок:** Отлов исключений (ошибки сети, API, лимиты) без падения основного процесса бота.
* UX/UI в Discord:** Отправка временного статуса («Думаю...») с последующим редактированием сообщения на итоговый ответ.

# Стек технологий
* Python 3.10+**
* discord.py** (асинхронная библиотека для Discord API)
* openai** (официальный SDK для работы с GPT)
